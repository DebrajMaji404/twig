🌿 Twig

A compact text encoding for nested JSON that cuts LLM token costs ~50-70% by declaring schema once instead of repeating braces, quotes, and keys per record. Try it below — encoding and decoding run as real Python (the same tested codec from the GitHub repo), not a JS reimplementation.

Known limitation: Twig currently can't distinguish "this field was never present in a record" from "this field is present but null" — every record gets every field declared in the schema. Harmless for most uses; matters if your app depends on key-presence checks. See the README for details and the reproducible test case.
Twig is MIT-licensed and open source. This page calls /api/encode and /api/decode, two small Python serverless functions running the exact codec from the repo — nothing here is reimplemented in JavaScript.
